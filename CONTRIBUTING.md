# Contributing to Code Minions

Thank you for your interest in contributing to Code Minions! 🎉

Even though this project started as a personal tool, contributions are welcome and appreciated.

## How to Contribute

There are several ways you can contribute:

- ✨ Adding new capabilities
- 🛠 Enhancing the CLI
- 📖 Improving documentation
- 🐛 Fixing bugs
- 💡 Suggesting new features

## Getting Started

1. Fork the repository
2. Clone your fork locally:
   ```powershell
   git clone https://github.com/YOUR-USERNAME/code-minions.git
   cd code-minions
   ```
3. Create a new branch for your changes:
   ```powershell
   git checkout -b feature/your-feature-name
   ```
4. Make your changes
5. Stage and commit your changes:
   ```powershell
   git add .
   git commit -m "docs: add CONTRIBUTING.md with contribution guidelines"
   ```
6. Push your branch to GitHub:
   ```powershell
   git push origin feature/your-feature-name
   ```
7. Open a Pull Request on GitHub

## Pull Request Guidelines

- Keep changes focused and minimal
- Provide a clear description of what your PR does
- Reference related issues if applicable (e.g., `Closes #16`)
- Ensure the project builds successfully

## Code Style

Follow the existing project structure and conventions.  
If applicable, run formatters or linters before submitting.
